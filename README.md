<h3 align="center">デザインの視点を持つフルスタックエンジニアを目指しています</h3>

<p align="center">
  編集デザイナー出身です。デザインの経験を土台に、<br>
  将来は企画・開発・デザインのすべてに関われるエンジニアを目指しています。<br>
  Java / Spring Boot と Next.js を学び、AI絵日記サービス「TADA」をチームで開発しました。
</p>

## 大切にしていること

<table>
  <tr>
    <td width="250"><b>👂 使う人の立場で考える</b></td>
    <td>依頼されたものをそのまま作るのではなく、<br>対話を通じて本質的な目的を捉えてから形にする</td>
  </tr>
  <tr>
    <td><b>🧭 わかりやすく整理して伝える</b></td>
    <td>複雑な情報や要望を整理し、<br>相手に伝わる形に可視化する</td>
  </tr>
  <tr>
    <td><b>🛡️ 中途半端な状態を残さない</b></td>
    <td>失敗したら全体を取り消せるよう、<br>トランザクションの範囲を意識して設計する</td>
  </tr>
  <tr>
    <td><b>🔍 原因を調べてから直す</b></td>
    <td>レビューで見つかった同時操作の問題は、<br>排他制御を追加して再発を防ぐ</td>
  </tr>
  <tr>
    <td><b>🧪 テストで確かめる</b></td>
    <td>主要な処理は、JUnit・Mockitoで<br>テストを書いて確認する</td>
  </tr>
</table>
